# Mihomo Rule Provider

这是一个用于存放 **Mihomo Rule Provider 规则片段** 的仓库。

规则按不同服务或用途分类整理，主要提供可直接订阅的 TXT 规则文件，方便在 Mihomo 配置中通过 `rule-providers` 引用。
